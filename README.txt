PNB PROMOTION MCQ WEBSITE

1. Open index.html to test the website locally.
2. To publish it online for free:
   - Create an account on GitHub or Netlify.
   - Upload index.html, style.css and app.js.
   - Deploy the website.

IMPORTANT:
This starter version stores posted MCQs in the browser. For a real multi-user website, the next step is to connect Firebase/Supabase for:
- Admin login
- Cloud database
- User accounts
- Leaderboard
- Question approval
